1Click NEAR Intents Examples

Reusable patterns for quoting, depositing, and tracking cross-chain trades. Use these for the hackathon mainnet $1000+ routes.

Quickstart Flow

Query tokens → request quote → send deposit → track status. Full docs: NEAR Intents 1Click Quickstart

1. Get Supported Tokens

curl https://1click.chaindefuser.com/v0/tokens

2. Request a Quote (dry run first)

curl -X POST https://1click.chaindefuser.com/v0/quote \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT" \
  -d '{
    "dry": true,
    "swapType": "EXACT_INPUT",
    "slippageTolerance": 100,
    "originAsset": "nep141:wrap.near",
    "depositType": "ORIGIN_CHAIN",
    "destinationAsset": "nep141:arb-0x912ce59144191c1204e64559fe8253a0e49e6548.omft.near",
    "amount": "1000000000000000000000000",
    "recipient": "0xYourAddress",
    "recipientType": "DESTINATION_CHAIN",
    "refundTo": "your.near",
    "refundType": "ORIGIN_CHAIN"
  }'

3. Execute (dry: false) then Deposit

Set dry: false. Response includes depositAddress. Send the exact amount to that address on the origin chain. Swap starts automatically.

4. Track Status

curl "https://1click.chaindefuser.com/v0/status?depositAddress=THE_DEPOSIT_ADDRESS"

For Agents

Same endpoints. Agents call quote → submit deposit → poll status. Wrap in proof bounds so the agent can only request routes that satisfy the coded invariant.
