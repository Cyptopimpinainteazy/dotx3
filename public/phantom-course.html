Who can rename the workshop?

The classroom policy gives the curator sole authority to change session labels. Review two instructor-written alerts against this snapshot. Both ask whether a label setter enforces that policy.

Decide each alert

Morning label · line 22
Evening label · line 26

Read the worked answer

Morning · dismiss. Line 22 attaches onlyCurator. Lines 17–20 reject a different caller before the write on line 23.

Evening · uphold. Line 26 has no curator check. Line 27 writes the label directly. A different caller can change that piece of schedule metadata.

Maintainer action. Apply the existing modifier to the evening setter. Verify that the curator can update both labels and another caller is refused with the previous values intact.

Scope. The schedule display was outside the supplied snapshot. Ask for its data-loading code before claiming students would see a changed label. These acceptance checks are proposed.
